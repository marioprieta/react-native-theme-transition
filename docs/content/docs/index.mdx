Theme transitions in React Native have always needed custom native modules. That means no Expo Go, no OTA updates, and extra maintenance for each platform.

This library takes a different approach: snapshot the current screen into a Skia Canvas, swap the theme underneath, and animate the captured snapshot away with a shader, a shape clip, or a simple cross-fade. The result is a set of smooth transitions that work everywhere, with no native code and no prebuild — every peer dependency ships with Expo Go.

## Features

- **9 transition styles.** Fade, circular reveal, heart, star, wipe, slide, split, pixelize, dissolve — all configurable per call via a typed discriminated union. Every reveal-style transition also supports an inverted direction.
- **Expo Go compatible.** No native code, no prebuilds. Powered by Skia and Reanimated, both ship with modern Expo SDKs.
- **Typed theme management.** Provider, single `useTheme` hook with deep generic inference for theme names and token keys.
- **System theme sync.** Follows OS appearance automatically with zero-flash startup and runtime switching. Respects Reduce Motion.
- **Transition-safe selection.** `select()` defers state changes by one frame so picker highlights appear correctly in the captured screenshot.
- **Transition guard.** Blocks concurrent transitions, exposes `isTransitioning`, never queues.
- **React Compiler ready.** All hooks follow the [Rules of React](https://react.dev/reference/rules).
- **Tiny footprint.** ~13 kB runtime, no vendored dependencies.

## Trade-offs

- **No interaction during transitions.** Touches, scrolls, and additional `setTheme` calls are blocked while the animation is running. Use `isTransitioning` to disable buttons.
- **Static overlay.** The transition uses a captured snapshot, so dynamic content (videos, animations, live counters) will appear frozen while the overlay is visible.
