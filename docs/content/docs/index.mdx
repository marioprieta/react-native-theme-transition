title: Overview
description: Smooth, animated theme transitions for React Native. Expo Go compatible, powered by Skia and Reanimated.
---

`react-native-theme-transition` brings native-feeling theme
switching to React Native without any custom native code. It
captures the current screen into a Skia canvas, swaps your theme
underneath, and animates the captured frame away with a shader, a
shape clip, a slide, or a fade. Everything runs on JS, Skia, and
Reanimated, so the library works in Expo Go with no prebuild.

## Highlights

- **Nine transition kinds.** `fade`, `circularReveal`, `heart`,
  `star`, `wipe`, `slide`, `split`, `pixelize`, `dissolve`. Picked
  per call via a typed discriminated union. Reveal-style transitions
  support an `inverted` variant.
- **Expo Go compatible.** No native modules, no prebuilds. Skia and
  Reanimated both ship with modern Expo SDKs.
- **Typed theme management.** One provider, one `useTheme` hook,
  full generic inference for theme names and token keys.
- **First-class system mode.** `useTheme()` exposes a `preference`
  field that can be `'system'` (for pickers and persistence), while
  `theme` always describes the concrete painted theme (for
  rendering).
- **Transition guard.** Concurrent `setTheme` calls return
  `'ignored'`, so you can wire buttons directly without writing your
  own queue.
- **React Compiler ready.** All hooks follow the
  [Rules of React](https://react.dev/reference/rules).
- **Tiny footprint.** Around 13 kB of runtime.

## Trade-Offs

- **No interaction during transitions.** Touches, scrolls, and
  additional `setTheme` calls are blocked while the animation is
  running. Use `isTransitioning` to disable buttons visually.
- **Static overlay.** The transition renders a captured snapshot,
  so dynamic content (videos, live counters) appears frozen for the
  duration of the animation.
- **No built-in Reduce Motion handling.** The library is
  policy-free on accessibility. If you want to honor the OS Reduce
  Motion setting, call `setTheme(name, { animated: false })` from
  your own wrapper.
