```ts
import type {
  ThemeDefinition,
  ThemeTransitionConfig,
  ThemeTransitionAPI,
  UseThemeResult,
  SystemThemeMap,
  SetThemeOptions,
  SelectOptions,
  OriginSpec,
  TransitionOrigin,
  TransitionType,
  ThemeNames,
  TokenNames,
} from 'react-native-theme-transition';
```

The library also exports two **runtime** values alongside these types:

```ts
import { TRANSITION_TYPES, useReducedMotion } from 'react-native-theme-transition';
```

- `TRANSITION_TYPES` — readonly array of every `TransitionType`, handy for
  pickers and validation without hardcoding the list.
- `useReducedMotion()` — hook returning `true` while the OS "Reduce Motion"
  accessibility setting is enabled. The library honors this internally when
  `reduceMotion: true` is set in config (the default); use the hook if you
  want your own components to react to the setting too.

## Types

### `ThemeDefinition`

```ts
type ThemeDefinition = Record<string, string>;
```

A flat record where keys are token names and values are color strings.

### `ThemeNames<T>`

```ts
type ThemeNames<T extends Record<string, ThemeDefinition>> = keyof T & string;
```

Union of theme name strings from your theme map.

### `TokenNames<T>`

```ts
type TokenNames<T extends Record<string, ThemeDefinition>> =
  keyof T[ThemeNames<T>] & string;
```

Union of token name strings shared across all themes.

### `SystemThemeMap<Names>`

```ts
type SystemThemeMap<Names extends string> = Record<'light' | 'dark', Names>;
```

Maps OS color schemes to theme names. Both keys required.

### `ThemeTransitionConfig<T>`

Configuration for `createThemeTransition`. See [API Reference](/docs/api/create-theme-transition).

| Field | Type | Description |
|---|---|---|
| `themes` | `T` | All themes keyed by name |
| `animated` | `boolean?` | Default animation on/off (default `true`) |
| `duration` | `number?` | Default transition duration in ms. Falls back to per-kind defaults when omitted (350 fade/reveal/strip, 800 shape, 750 shader) |
| `transition` | `TransitionType?` | Default transition style (default `'fade'`) |
| `reduceMotion` | `boolean?` | Honor OS reduce-motion setting (default `true`) |
| `backgroundColor` | `(colors) => string` | Root background color getter — defaults to the first token in the current theme |
| `darkThemes` | `ThemeNames<T>[]?` | Themes using dark color scheme for native UI sync |
| `systemThemeMap` | `SystemThemeMap?` | OS appearance mapping |
| `onTransitionStart` | `(name) => void` | Animated transition start |
| `onTransitionEnd` | `(name) => void` | Animated transition end |
| `onThemeChange` | `(name) => void` | Any theme change |

### `ThemeTransitionAPI<T>`

Return type of `createThemeTransition`. Contains `ThemeTransitionProvider` and `useTheme`.

### `UseThemeResult<Tokens, Names>`

The return type of `useTheme()`. Contains everything you need to read colors, change the theme, and build selection UIs.

| Field | Type | Description |
|---|---|---|
| `colors` | `Record<Tokens, string>` | Current color values |
| `name` | `Names` | Active theme name (never `'system'`) |
| `setTheme` | `(name \| 'system', opts?) => boolean` | Trigger a theme change |
| `isTransitioning` | `boolean` | Transition overlay is visible |
| `selected` | `Names \| 'system'` | Currently selected option (for picker UIs) |
| `select` | `(option, opts?) => void` | Select a theme with transition-safe timing |

### `SetThemeOptions<Names>`

Discriminated union on `transition`. The fields available depend on which transition you choose — TypeScript will only accept combinations valid for the picked type.

| Common field | Type | Description |
|---|---|---|
| `animated` | `boolean?` | Override config-level animation flag |
| `duration` | `number?` | Override duration for this call |
| `easing` | `(t: number) => number` | Reanimated easing function |
| `onTransitionStart` | `(name) => void` | Per-call start callback |
| `onTransitionEnd` | `(name) => void` | Per-call end callback |

| When `transition` is... | Extra field | Type |
|---|---|---|
| `'circularReveal'`, `'heart'`, `'star'` | `origin` | `OriginSpec` (point `{x,y}` or `ref`) — defaults to screen center |
| `'circularReveal'`, `'heart'`, `'star'` | `inverted` | `boolean` — by default the new theme grows from the origin outward; when `true`, the old theme shrinks into the origin point instead (default `false`) |
| `'wipe'`, `'slide'` | `direction` | `'left' \| 'right' \| 'up' \| 'down'` (default `'left'`) |
| `'split'` | `axis` | `'horizontal' \| 'vertical'` (default `'horizontal'`) |
| `'pixelize'` | `blockSize` | `number` — max block size in points (default `52`) |
| `'dissolve'` | `grainSize` | `number` — noise cell size in points (default `5`) |

```ts
// Default fade
setTheme('dark')

// Wipe from the right with custom duration
setTheme('dark', { transition: 'wipe', direction: 'right', duration: 500 })

// Circular reveal from a button, old theme shrinks inward
const btnRef = useRef<View>(null)
setTheme('dark', { transition: 'circularReveal', origin: btnRef, inverted: true })

// Pixelize with a custom block size
setTheme('dark', { transition: 'pixelize', blockSize: 32 })
```

### `SelectOptions<Names>`

Same as `SetThemeOptions` minus `animated` and callbacks — `select()` manages those internally.

### `OriginSpec`

```ts
type OriginSpec = { x: number; y: number } | React.RefObject<View | null>
```

Either an explicit point or a ref whose center will be measured.

### `TransitionType`

```ts
type TransitionType =
  | 'fade'
  | 'circularReveal'
  | 'wipe' | 'slide' | 'split'
  | 'heart' | 'star'
  | 'pixelize' | 'dissolve'
```

The `TRANSITION_TYPES` runtime constant is also exported — handy for building a transition picker without hardcoding the list.

`TransitionType` is derived from `TRANSITION_META`, so adding a new transition in source updates both the type union and `TRANSITION_TYPES`.

## Type inference example

```ts
const light = { bg: '#fff', text: '#000' };
const dark  = { bg: '#000', text: '#fff' };

const api = createThemeTransition({ themes: { light, dark } });

const { colors, name, setTheme } = api.useTheme();

colors.bg         // type: string, autocomplete: 'bg' | 'text'
colors.foo        // TypeScript error
name              // type: 'light' | 'dark'
setTheme('dark')  // ok
setTheme('ocean') // TypeScript error
setTheme('system')// always valid
```

## When to import these types

| Building... | Import |
|---|---|
| A theme picker component | `UseThemeResult`, `SelectOptions` |
| A ThemeBridge component | `ThemeNames` |
| Passing options to `setTheme` | `SetThemeOptions` |
| Typing the config object | `ThemeTransitionConfig` |
| Working with system theme mapping | `SystemThemeMap` |
| Custom transition origin | `OriginSpec`, `TransitionOrigin` |
| Enumerating transition styles | `TransitionType`, `TRANSITION_TYPES` |
